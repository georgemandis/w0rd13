# w0rd13 in detail

The longer notes. The [README](../README.md) has the short version.

## The game

Five words a day. Each word comes with a few guesses already played; read the colours, work out the only word that fits, and type it. One guess per word, and the clock runs the whole time.

- **Length and difficulty.** Word length runs from 3 to 10 letters. Difficulty sets how many clues you get: Easy (4), Normal (3), Hard (2), Extreme (1).
- **Vocabulary.** Standard uses the full answer list. Everyday limits answers to the most common spoken words (by OpenSubtitles frequency), which makes puzzles easier.
- **Themes.** Twenty five-letter packs (Animals, Food & drink, Body parts, Music, The outdoors, Colours, Sports, Space, Spooky, Weather, Jobs, Games, Ocean, Feelings, Tech, Fashion, Home, Drinks, plus Purple Rain and Swiftie built from song titles). A theme narrows the field, so clues only need to separate the answer from the rest of the pack, which makes Hard and Extreme far more playable. "Loose" packs like Purple Rain can carry names and spellings like DIE4U; the keyboard grows a digit row and pack words are always accepted as guesses.
- **Countdown.** A 3:00 fuse across all five words. A wrong guess burns 15 seconds, zero means the run explodes, and the share text reports how much time you had left.
- **Daily and Bonus.** Bonus is a second puzzle for the same day with a different seed. Nothing else changes.
- **Give up** ends the run: forfeited words show as 🏳️ in the share text and their answers are revealed.

Every combination is uniquely solvable: the generator searches for clues whose feedback rules out every other word in the answer list.

## URL parameters

Settings live in the URL so a setup can be shared. A bare URL is always the standard game: 5 letters, 3 clues.

| Parameter | Values |
| --- | --- |
| `letters` | 3 to 10 |
| `difficulty` | `easy`, `normal`, `hard`, `extreme` |
| `pack` | a theme id, e.g. `animals`, `purple` |
| `vocab` | `standard`, `everyday` |
| `clock` | `stopwatch`, `countdown` |
| `budget` | countdown length in seconds |
| `mode` | `daily`, `bonus` |
| `date` | `YYYY-MM-DD`, to play a past day (future dates are refused) |
| `game` | `orbit` for the second game, below |

Examples: `/?letters=7&difficulty=extreme`, `/?pack=animals&clock=countdown&mode=bonus`.

## Orbit (secret mode, in progress)

Open `/?game=orbit` for a second game built on word meaning. Words related to a secret word orbit it, farthest first; each miss reveals a closer ring, colours the letters you guessed, and lands your guess on the orbit at its own distance. You're told the category, and get five guesses per word. The Game control in settings only appears once you've arrived via that link.

Neighbours come from `src/words/hubs.ts` and `src/words/neighbors.ts`, precomputed by the scripts in `proto/orbit/` from a rank-averaged blend of GloVe and a BGE embedding. The vector files are not committed. To rebuild them:

```sh
cp .env.example .env            # fill in CF_ACCOUNT_ID and CF_TOKEN (Workers AI access)
bun proto/orbit/embed.ts        # BGE vectors via Workers AI -> proto/orbit/vectors.json
bun proto/orbit/embed-glove.ts path/to/glove.6B.100d.txt   # -> proto/orbit/vectors-glove.json
bun proto/orbit/build-hubs.ts
bun proto/orbit/build-neighbors.ts
```

GloVe is public domain: https://nlp.stanford.edu/projects/glove/ (glove.6B.zip).

## Sharing

`src/game/share.ts` builds the score. The first three lines match the classic format; a per-word breakdown follows so you can see which word got you. A perfect run earns a random good award emoji and a rough one (two or fewer right) earns a random bad one.

```
w0rd13
Bonus September 9, 2026
🟩🟩🟩🟩🟩 2:55 🦄

🟩 0:07
🟩 0:34
🟩 1:44
🟩 0:16
🟩 0:14
```

## History and themes

Each finished game is saved in the browser under its date and full setup, so you can play several setups a day. The intro lists what you've played today; the results screen has a "Play another setup" button. "Your week" shows days played, current streak, perfect runs and best standard time, then one row per day for the past week. Tap a played day to revisit it, or an unplayed one to play it late.

Colour themes (Classic, Slate, Noir, Bubblegum, Citrus, Game Boy, Terminal, "I Would Die 4 u" and "Down to Clown") are picked from the header and remembered in the browser.

## How it works

- `src/api.ts` is the game API, written against standard Request and Response so it runs under Bun (`src/server.ts`) and as a Worker (`src/worker.ts`). `/api/puzzle` returns the clues for the daily or bonus puzzle (answers stay on the server); `/api/guess` validates a guess and returns the answer and feedback.
- `src/game/puzzle.ts` generates puzzles deterministically from the date, mode, length and difficulty, so everyone gets the same words. Early clues split the candidates greedily; the final clue is searched for specifically so that exactly one word in the answer list fits all of them.
- `src/game/feedback.ts` is green, yellow and grey scoring for any word length with correct repeated-letter handling.
- `src/words/byLength.ts` holds the answer, allowed-guess and everyday lists for every length, built by `scripts/build-words.ts`: a word must be common in both web text (Norvig's Google unigram counts) and speech (OpenSubtitles frequencies), be a lowercase entry in `/usr/share/dict/words`, and not be a proper name (the system propernames file plus a blocklist, with an allowlist for names that are ordinary words like "will" and "mark"). The top few hundred to fifteen hundred per length are kept, plus every five-letter theme word. Allowed guesses are every dictionary word of that length. A gitignored `src/words/overrides.ts` (created from `overrides.example.ts` on install) can replace the lists for any length with private ones.
- Analytics are Plausible, on only when `PLAUSIBLE_SCRIPT_ID` is set at build time (see `.env.example`). Page views plus a few custom events: game started, game finished with outcome, gave up, exploded, score copied.
